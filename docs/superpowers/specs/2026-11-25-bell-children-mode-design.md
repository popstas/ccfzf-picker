# Звонок WezTerm: режим «без детей» — дизайн

Короткий дизайн. Два репозитория: ccfzf-picker (кнопка на три состояния) и
windows11-manager (список окон детей и `wezterm/wezterm.lua`).

## Зачем

Запрос Стаса 25.11: «нужно добавить 2 режима звуковых уведомлений: для обычных
сессий и для дочерних. Почему: мне больше не интересно, что дочерняя сессия
закончила, пока мне об этом не сказала родительская».

Сегодня звонок один на все окна WezTerm: кнопка `#bell-button` в статуслайне
пикера кладёт или снимает флаг `~/.wezterm-bell-off`
(`src-tauri/src/wezterm_bell.rs`), обработчик `wezterm.on('bell')` в
`windows11-manager/wezterm/wezterm.lua` молчит, пока флаг есть. Кто
зазвонил, обработчик не знает.

## Цели

- Три режима звонка: `all` (звенят все — сегодняшнее «вкл», умолчание),
  `no children` (звенят все, кроме дочерних), `off` (не звенит никто —
  сегодняшнее «выкл»).
- Одна кнопка — та же `#bell-button`, щелчок по кругу `all → no children →
  off → all`; у каждого состояния свой глиф и `title` (по-английски).

## Не цели

- Windows Terminal: там звонок системный, по сессиям не выключается. Режим
  только для WezTerm, как и нынешняя кнопка.
- Мак: звонок своим звуком заведён только на Windows (кнопка там скрыта) —
  без изменений. Мак недоступен.
- Мигание кнопок на панели задач, кружки в пикере — не трогаются. Только звук.

## Анти-цели

- Замолчавшая обычная сессия. Ошибка в сторону «звенит лишний ребёнок»
  допустима, в сторону «молчит head» — нет: список детей протух, файла нет,
  менеджер лежит — звенят все (fail-open).
- WezTerm, поставленный без пикера и без файлов, звенит как раньше.

## Решения Стаса 25.11

- **Одна кнопка на три состояния**, не два переключателя: четвёртое
  состояние «звенят только дети» смысла не имеет (предложено head, принято).
- **1a. Дочерняя — любая сессия с head**: открытая `session-spawn`,
  привязанная `head adopt`, а также coord и внуки (у них тоже есть кому
  доложить). Head без родителя — обычная. Источник —
  `~/.ccfzf/children/<sid>.json` на машине агентов (с Windows — тот же каталог на сетевом диске;
  `head adopt` пишет туда же с `adopted: true`), плюс местный
  `child-registry.js` менеджера — он знает ребёнка от `session-spawn` сразу,
  до SMB.
- **2a. Список детей для WezTerm пишет менеджер**, а не пикер: ребёнок
  попадает в список на ближайшем такте, и работает это при закрытом пикере
  (скрытый пикер опрашивает до 8 мин). Пикер только ставит режим.

## Поведение

- **Режим — флаг-файлы в профиле** (`USERPROFILE`, тот же каталог, что у
  `.wezterm-bell-off`):
  - `.wezterm-bell-off` есть → `off` (как сегодня; старые установки не
    ломаются);
  - иначе `.wezterm-bell-children-off` есть → `no children`;
  - иначе → `all`.
  Пикер ставит и читает режим командами `wezterm_bell` / `set_wezterm_bell`
  (ответ — то, что лежит на диске после операции, как сегодня), состояние
  кнопки берётся из ответа Rust на старте, на `picker-shown` и после клика.
  Имена файлов — контракт двух репозиториев, сторож в обоих.
- **Список детей** — файл в том же профиле (имя — на выбор строителя,
  например `.wezterm-bell-children`), пишет служба/демон windows11-manager:
  по строке на окно WezTerm дочерней сессии этой машины, ключ — то, что
  обработчик может сверить с `pane:get_title()` / `window`-заголовком
  (заголовок окна после снятия приставок — `stripTitleDecoration` и
  `[Z] [i/n] ` WezTerm; спиннер/✳ Claude Code в начале заголовка — тоже).
  Переписывать только при изменении содержимого. Ребёнка ищет по sessionId,
  а заголовок берёт у привязанного окна — имя ребёнка меняется (`/rename`,
  хук ветки).
- **`wezterm.lua`**: на звонке `off` → молчать; `no children` → прочитать
  список, нормализовать заголовок зазвонившей панели тем же правилом и
  молчать, если он в списке; иначе играть. Файла списка нет или не читается —
  играть.

## Оставлено строителю

- Формат и имя файла списка, правило нормализации заголовка (одно на обе
  стороны, со сторожем).
- Кто в менеджере пишет список (демон с его тиком или служба иконок) — где
  уже есть привязка sessionId → окно.
- Глифы трёх состояний кнопки (в духе нынешних `bell-on` / `bell-muted`).
- Выкатка: windows11-manager (`wezterm.lua` и node) — `deploy-pc.sh`, пикер —
  `deploy-win.sh`, оба на nb; сначала менеджер.
