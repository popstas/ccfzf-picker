# Галка `hide dimmed windows` — дизайн

Короткий дизайн, маленькая правка одного репозитория (ccfzf-picker).
Продолжение `2026-11-24-taskbar-hide-dimmed-design.md` — служба, маршрут,
набор и исключение «сигнал держит кнопку» не меняются.

## Зачем

Запрос Стаса 25.11: «hide dimmed → hide dimmed windows (только скрывает окна в
таскбаре, а в пикере оставляет), hide dimmed (работает как раньше)».

Сейчас кнопки погашенных прячутся только связкой: опция `hideDimmedFromTaskbar`
в `config.yaml` **и** галка `hide dimmed` (`hideStale`) **и** `dim stale`
(`taskbarHideEnabled` в `sessions.html`). Спрятать кнопки на панели задач,
оставив строки в пикере, нельзя — это и чинится.

## Цели

- Новая галка статуслайна `hide dimmed windows` (ключ `hideDimmedWindows`):
  прячет кнопки погашенных сессий этой машины с панели задач, строки в пикере
  не трогает.
- `hide dimmed` (`hideStale`) — как до фичи панели задач: прячет строки
  в пикере, кнопки на панели не трогает.
- Галки независимы; обе включены — оба эффекта.

## Не цели

- Служба windows11-manager, маршрут `/claude-wt/taskbar-hide`, тело набора,
  `taskbarHideSets` и `hasSignal` — без изменений.
- CLI `claude-wt window taskbar` — не трогается.

## Анти-цели

- Кнопки, мигающие от набора в поиске: набор по-прежнему следует за галкой, а
  не за `activeFilters` (правило в `docs/rules/filtering.md`).
- Включённая у Стаса сегодня связка после обновления молча перестала прятать
  кнопки (см. миграцию).

## Подходы (решение Стаса 25.11: 1a 2a 3a)

1. Независимы ли галки. **a (выбрано)** — полностью независимы, одна галка —
   одно действие. b — `hide dimmed` прячет и строки, и кнопки, а новая — только
   кнопки: отвергнуто, «работает как раньше» = как до фичи панели задач, и две
   галки с пересекающимся смыслом путают.
2. Опция `hideDimmedFromTaskbar` в `config.yaml`. **a (выбрано)** — убрать,
   её заменяет галка; состояние в `ui.json`, как у соседей. Миграция: если в
   загруженном конфиге `hideDimmedFromTaskbar: true`, а в `ui.json` ключа
   новой галки ещё нет — галка стартует включённой (ось `list: true`). b —
   оставить главным выключателем: отвергнуто, два выключателя одного действия.
3. Где галка. **a (выбрано)** — в статуслайне (`statusline: true` по
   умолчанию), сразу за `hide dimmed`, ось `list` по умолчанию `false`.
   Показывать только там, где у неё есть эффект — Windows (панель задач есть
   только там, служба — windows11-manager); на маке и прочих в статуслайне её
   нет. b — только в окне настроек: отвергнуто, Стас просил быстрый щелчок.

## Поведение

- `taskbarHideEnabled()` = `toggles.hideDimmedWindows === true &&
  staleSettings().enabled === true`. `hideStale` в условие больше не входит.
- Щелчок `hide dimmed windows` и `dim stale` зовёт `resendWindowSets()`;
  `hide dimmed` больше не зовёт (на набор не влияет). `hide dimmed windows`
  состав списка не меняет — не фильтр, `regroup` не нужен (в `FILTER_KEYS`
  не попадает; группа `side` — на выбор строителя, но визуально рядом с
  `hide dimmed`).
- `dim stale` по-прежнему обязательна: ничего не погашено — нечего прятать.
- Поле `hideDimmedFromTaskbar` уходит из `settings-form.js` (вкладка гашения);
  `config-shape.js` ключ читает только ради миграции (или миграция в Rust/там,
  где ui.json нормализуется, — на выбор строителя), в `config.yaml` окно
  настроек его больше не пишет.
