# Режим 2/3 в широкой раскладке — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** переключатель на вкладке Layout panels — «поровну» или «2/3»; при «2/3», когда в широкой раскладке (`^F`) на экране ровно колонки 1 и 3, первая занимает 2/3 ширины, третья — 1/3.

**Architecture:** восьмое поле `ui.json` — `wideSplit: 'equal' | 'twoThirds'`, умолчание `equal`. Правило — чистая функция `wideColumnGrow(columns, split)` в `frontend-src/picker-sections.js`. `renderWide` в `sessions.html` при пересборке каркаса вешает колонке с весом 2 класс `grow-2`, CSS даёт ему `flex-grow: 2`; `wideSplit` входит в отпечаток каркаса, иначе правка из настроек не дошла бы до экрана. Вкладка Panels в `settings.html` — выпадашка между широкой и узкой таблицами, пометка правки — в том же `dirtyPanels`.

**Tech Stack:** ванильный JS (UMD-модули: `<script>` в окнах и `require` в тестах), CSS flex, `node --test` через `npm test`.

**Spec:** слова Стаса (12.11, через head-сессию): «сейчас заняты колонки default + 3, в этом случае default должна быть на 2/3 ширины, а колонка 3 на 1/3». Ответы на вопросы (12.11): нужен переключатель на вкладке Layout panels, «поровну» или «2/3», по умолчанию «поровну» (выбор head); 2/3 действует только для набора колонок `{1, 3}` — колонка 1 получает 2/3, колонка 3 — 1/3; во всех остальных наборах поровну, три колонки — по 1/3.

«default» — значение выпадашки `column` на вкладке Layout panels: «колонку назначает смысл секции» (`live` и `zellij` → 1, `remote` → 2). `renderWide` видит только итоговый `section.column`, поэтому правило сформулировано по нарисованным колонкам, а не по записям `ui.json`.

- Имена машин в репозиторий не писать (`test/no-private-data.test.js`). В worktree без `data/` эта проверка пропускается, поэтому перед мержем — `npm test` в основном каталоге.
- `uiStateToSave` зовётся всеми аргументами во всех трёх местах (`settings.html` дважды, `sessions.html` один раз), и сторожа сверяют список дословно (`docs/rules/settings-and-ui-state.md`, первое правило).
- Нелогичное значение `wideSplit` в файле читается как `equal`: испорченный файл не должен менять человеку ширину.
- Временные колонки перетаскивания (`.drop-zone`, `flex: 0 0 96px`) веса не получают.
